# v1.1 路线图

> 状态：待评审 / 待开发
> 范围：在保持 `formatVersion = 1` 向后兼容的前提下，向 `CourseManifest` 添加新的可选字段与新动作/触发器/动画能力。
> 兼容性策略：所有新字段均 `WhenWritingNull` 忽略；所有新枚举值不破坏旧解析（解析器遇到未知值忽略/记录 warning 而非抛错）。

---

## 1. 目标（Goals）

1. 让设计者能控制图片填充方式与加载策略，避免在 XAML 中重复写 `Stretch` / 占位色。
2. 把动画的"可动属性"从 7 个扩到 15+ 个，补齐 easing 词表，让"改字、改圆角、改背景色"成为一等公民。
3. 把交互事件从 4 种扩到 14+ 种（Pointer 家族、Hold、Swipe、Drag、Scroll、Focus），并支持组合键 / 单次触发 / 去抖。
4. 补齐媒体控制、StepReveal、变量、窗口动作，使现有 StepReveal 控件真正可被触发器驱动。
5. 页面维度新增 `hidden` / `section` / 自定义 `transition` 时长，支持章节化课件。
6. 题型新增 `FillInBlank`，Quiz 支持部分得分。
7. 升级 `formatVersion` 兼容矩阵：解析器能区分"未知字段"和"未知值"，并把诊断写进 manifest 的 `diagnostics` 节点。

---

## 2. 非目标（Out of Scope，延后到 v2+）

- 路径动画（MotionPath）、关键帧（keyframe）
- 九宫格切图、阴影/模糊滤镜
- 拖拽题、连线题、热区题、简答题
- 计时、题库、随机抽题
- 多语言切换、RTL
- 自定义 ResourceDictionary 主题
- DRM / 过期 / 域锁
- SCORM / xAPI 导出
- 演讲者批注、Spotlight、墨迹
- 视频导出、HTML5 导出

## 3. 详细任务清单

### T1. AssetDescriptor 扩展

新增可选字段（均 nullable，旧 manifest 不受影响）：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | enum string | `"binary"` | 旧值 `"binary"` 等价于 `"raw"`；新增 `image` / `video` / `audio` / `font` / `lottie` |
| `fit` | enum string | `"stretch"` | `none` / `fill` / `contain` / `cover` / `stretch` |
| `placeholderColor` | string `#AARRGGBB` | `null` | 加载前底色，AssetBinder 解析后写入 Image 的 `Background` |
| `preload` | enum string | `"eager"` | `eager` / `lazy` / `metadata`（lazy 在页面停留 ≥0.5s 后才下载） |

**落地位置**
- `Core/Models/CourseManifest.cs`：`AssetDescriptor` 加 4 个属性 + `[JsonPropertyName]` + `[JsonIgnore(Condition = WhenWritingNull)]`
- `Runtime/Player/AssetBinder.cs`：枚举 `AssetFit` / `AssetType` / `AssetPreload`；解析后写入 `Image` 对应属性

**向后兼容**
- 旧 manifest 缺 `fit` → 默认 `stretch`（行为与原 `BitmapImage` 的默认 Stretch 一致）
- 旧 manifest 缺 `preload` → `eager`（与现状一致）
- `type` 仍接受 `"binary"`，运行时映射为 `raw`

### T2. PageDescriptor 扩展

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `hidden` | bool | `false` | 演示流程跳过（仍可在编辑器和演讲者备注页可见） |
| `section` | string | `null` | 章节名（用于目录/分组） |
| `transitionDurationMs` | int? | `null` | 覆盖 PageTransitionFactory 的 320ms 默认 |
| `background` | string `#AARRGGBB` | `null` | 覆盖 stage 背景，仅本页生效 |

**落地位置**
- `Core/Models/CourseManifest.cs`：`PageDescriptor` 加 4 个属性
- `Runtime/Player/PagePlayer.cs`：`GoToAsync` 读取 `descriptor.TransitionDurationMs` 传给 `PageTransitionFactory`
- `Runtime/Player/PageTransitionFactory.cs`：所有动画方法接受可选 `ms` 参数
- `MainWindow.xaml.cs`：`GoToIndexAsync` / `NextAsync` / `PreviousAsync` 跳过 `hidden` 页

**行为变更**
- `NextAsync` / `PreviousAsync` 跳过 `hidden = true` 的页
- 演讲者视图的"下一页缩略图"指向"下一个可见页"

### T3. AnimationDescriptor 扩展

**T3.1 新增可动属性**（`StoryboardFactory.ResolvePropertyPath` 加分支）：

| 名称 | TargetProperty 路径 | 适用 |
|---|---|---|
| `Width` | `(FrameworkElement.Width)` | FrameworkElement |
| `Height` | `(FrameworkElement.Height)` | FrameworkElement |
| `Margin` | `(FrameworkElement.Margin)` | FrameworkElement（Double 不够，需要 thickness 单独处理 — 见 T3.3） |
| `CornerRadius` | `(Microsoft.UI.Xaml.Controls.Border.CornerRadius)` | Border |
| `FontSize` | `(Control.FontSize)` | TextBlock / Control |
| `BackgroundColor` | `(Panel.Background).(SolidColorBrush.Color)` | Panel / Border |
| `BorderColor` | `(Border.BorderBrush).(SolidColorBrush.Color)` | Border |

> 上述路径需要在 `ResolvePropertyPath` 中显式枚举，与 README 已记录的"静默失败需显式枚举"原则一致。

**T3.2 补齐 easing**（`EasingParser.Parse` 加分支）：

新增：`EaseInBack` / `EaseInElastic` / `EaseInBounce` / `EaseInQuad` / `EaseOutQuad` / `EaseInOutQuad` / `EaseInCirc` / `EaseOutCirc`

**T3.3 Thickness 动画（备选）**

`Margin` / `Padding` 这类 `Thickness` 属性需要 `ThicknessAnimation` 而非 `DoubleAnimation`。v1.1 先不实现 `Margin`，但要在 `ResolvePropertyPath` 中显式 throw `NotSupportedException` 并给出明确信息，避免静默失败。

**落地位置**
- `Runtime/Animations/StoryboardFactory.cs`：`ResolvePropertyPath` 扩枚举
- `Runtime/Animations/EasingParser`（同文件）：`Parse` 加分支
- `Core/Models/Animations.cs`：`AnimationDescriptor` 加 `property` 注释列出完整支持列表

**预设动画同步更新**
- `Runtime/Animations/PresetAnimations.cs`：补 `FadeInLeft` / `FadeInRight` / `PopIn` / `Bounce`（用新 easing）

### T4. Trigger 扩展

**T4.1 新事件类型**（`TriggerEngine.Bind` 加 switch case）：

| `on.type` | 绑定目标 | 备注 |
|---|---|---|
| `PointerEnter` | `UIElement.PointerEntered` | |
| `PointerExit` | `UIElement.PointerExited` | |
| `PointerPressed` | `UIElement.PointerPressed` | |
| `PointerReleased` | `UIElement.PointerReleased` | |
| `DoubleClick` | `UIElement.DoubleTapped` | |
| `Hold` | `UIElement.Holding` | e.HoldingState == Started |
| `SwipeLeft` / `SwipeRight` / `SwipeUp` / `SwipeDown` | `UIElement.ManipulationDelta`（X/Y 累积） | 阈值默认 80px |
| `Scroll` | `ScrollViewer.ViewChanged` | 监听 IsIntermediate 变化 |
| `Focus` / `LostFocus` | `Control.GotFocus` / `LostFocus` | |
| `Drag` | `UIElement.ManipulationStarting` + `ManipulationDelta` | 见 T4.4 |
| `Drop` | `UIElement.Drop` | |
| `MediaEnded` | `MediaElement.MediaEnded` | |

**T4.2 `on` 字段扩展**（`TriggerEvent` 加属性）：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `tapCount` | int? | `null` | 1=单击, 2=双击, 3=三击；不设则不区分 |
| `modifiers` | List<string> | `[]` | `Ctrl` / `Shift` / `Alt`；仅 `Key` 事件使用 |
| `debounceMs` | int? | `null` | 去抖窗口（ms） |
| `once` | bool | `false` | 一次性触发，触发后自动 `Detach` |

**T4.3 修复合并 bug**
- `RebindToPage` 时如果 `once = true` 已触发，handler 已 Detach，无需再处理
- `Key` 事件增加 `modifiers` 校验：当前只比较 `e.Key == vk`，应改成同时校验 `e.KeyStatus.IsExtendedKey` + `modifiers`

**T4.4 Swipe / Drag 阈值**
- 引入 `GestureThresholds` 静态类，默认 Swipe=80px，Drag 起始需要 ≥10px 位移
- 状态机：在 Bind 时用 `_activeManipulations` Dictionary<element, gestureState> 跟踪

**落地位置**
- `Core/Models/Triggers.cs`：`TriggerEvent` 加 4 个属性
- `Runtime/Triggers/TriggerEngine.cs`：所有 Bind 方法 + 新增 `BindSwipe` / `BindDrag` / `BindHold` / `BindScroll`
- `Runtime/Triggers/GestureThresholds.cs`（新文件）：阈值常量

### T5. Action 扩展

**T5.1 媒体控制**（`ActionExecutor.ExecuteAsync` 加 case）：

| `type` | 参数 | 行为 |
|---|---|---|
| `PlayMedia` | `target`, `from` (TimeSpan) | 找到 `MediaElement`，`Play()` |
| `PauseMedia` | `target` | `Pause()` |
| `StopMedia` | `target` | `Stop()` |
| `SeekMedia` | `target`, `to` (TimeSpan 秒数) | `Position = TimeSpan.FromSeconds(to)` |
| `SetVolume` | `target`, `value` (double 0-1) | `Volume = value` |
| `Mute` | `target`, `value` (bool) | `IsMuted = value` |

**T5.2 StepReveal 控制**：

| `type` | 参数 | 行为 |
|---|---|---|

| `ResetSteps` | `target` | 调 `Reset()` |

**T5.3 导航扩展**：

| `type` | 参数 | 行为 |
|---|---|---|
| `FirstPage` | — | `GoToIndexAsync(0)`，跳过 `hidden` |
| `LastPage` | — | 跳到最后一页（也跳过 hidden） |
| `GoBack` | — | 历史栈，需在 `PagePlayer` 内维护 `List<string>` |

**T5.4 窗口动作**：

| `type` | 参数 | 行为 |
|---|---|---|
| `OpenHyperlink` | `url` | `Launcher.LaunchUriAsync(new Uri(url))` |
| `OpenFile` | `path` | `Launcher.LaunchFileAsync(...)` |
| `ExitPresentation` | — | `App.Current.Exit()` |
| `ToggleFullscreen` | — | 调 `MainWindow.OnFullscreenClicked` 逻辑（需要把逻辑抽到 PagePlayer / App） |

**T5.5 Quiz 控制**：

| `type` | 参数 | 行为 |
|---|---|---|
| `SubmitQuiz` | `target` | 调 `QuizControl.Submit()` |
| `ResetQuiz` | `target` | 调 `QuizControl.Reset()` |
| `ShowFeedback` | `target` | 写 `ShowFeedback=true` |
| `HideFeedback` | `target` | 写 `ShowFeedback=false` |

**T5.6 变量（基础）**：

| `type` | 参数 | 行为 |
|---|---|---|
| `SetVariable` | `name`, `value` (任意 JSON) | 写 `Variables[name] = value` |
| `IncrementVariable` | `name`, `by` (double, 默认 1) | 数值自增 |
| `ToggleVariable` | `name` | bool 取反 |

**T5.7 动画控制**：

| `type` | 参数 | 行为 |
|---|---|---|
| `StopAnimation` | `target`, `animation` | 找到 `Storyboard`（需要缓存或重新 Build）后 `Stop()` |
| `PauseAnimation` / `ResumeAnimation` | `target`, `animation` | `Pause()` / `Resume()` |

**落地位置**

### T6. Quiz 扩展

**T6.1 新题型 `FillInBlank`**

- `QuizMode` 加 `FillInBlank`
- `QuizControl` 加 `Blanks` 集合（每个空 = 一个 `QuizBlank`，含 `Pattern`（正则或 `*` 通配）、`CaseSensitive`）
- 提交时按空顺序匹配用户输入，全部命中判对
- v1.1 限制：单行文本输入；不设上限但建议 ≤5 个空

**T6.2 部分得分**

- `QuizControl` 加 `ScoreStrategy` 枚举：`AllOrNothing`（默认，向后兼容）/ `PartialCredit` / `Proportional`
- `AllOrNothing`：现状
- `PartialCredit`（多选）：`correct = min(选对的, 没选的) / totalCorrect`，惩罚错选
- `Proportional`：纯命中比例 `correctSelected / totalCorrect`，不惩罚

**落地位置**
- `Core/Models/CourseManifest.cs`：无需改（`QuizMode` 在 XAML 中以字符串赋值）
- `Runtime/Controls/QuizControl.cs`：加 `QuizBlank` 嵌套类 + `Blanks` 集合 + `ScoreStrategy` 枚举 + 计分改写
- `Runtime/Themes/Generic.xaml`：FillInBlank 模式的 ControlTemplate（TextBox 列表 + Submit）

### T7. 兼容性诊断

**T7.1 解析器软失败**

- `Core/Packaging/CoursePackage.cs::DeserializeManifest` 改成捕获 `JsonException` 并尝试"严格 + 宽松"两轮解析；失败时抛 `InvalidDataException` 并附 diagnostics
- `Runtime/Triggers/TriggerEngine` / `ActionExecutor` 遇到未知 `on.type` / `action.type` 时，`Debug.WriteLine` 但不抛
- `Runtime/Animations/EasingParser` 遇到未知 easing：保留现状（fallback 到 `EaseOutCubic`），但加 warning 日志
- `Runtime/Animations/StoryboardFactory` 遇到未知 property：抛 `NotSupportedException`（保持现状以避免静默失败），但消息要带 property 名

**T7.2 诊断输出**

- `CourseManifest` 加可空 `Diagnostics` 节点（运行时填充，序列化时跳过）：
  ```
  diagnostics: {
    warnings: [{ code, message, location }],
    errors:   [{ code, message, location }]
  }
  ```
- v1.1 由运行时收集但不写回 manifest；编辑器可以显示

**落地位置**
- `Core/Models/CourseManifest.cs`：`Diagnostics` 字段 + `DiagnosticEntry` / `DiagnosticCollection` 类型
- `Core/Packaging/CoursePackage.cs`：`DeserializeManifest` 双轮解析
- `Runtime/Player/PagePlayer.cs`：`StartAsync` 汇总 warnings 并在演讲者视图"页面"按钮里显示红点

## 6. 验收标准（Definition of Done）

1. 所有单元 / 集成测试通过。
2. `HelloWorld.fcourse` + 一个"v1.1 maximal"样例均能正常打开与播放。
3. 任意字段缺失或未知值都不导致崩溃，最多弹 TeachingTip。
4. 演讲者视图的下一页缩略图永远指向"下一个可见页"。
5. README / fcourse-format.md 已同步更新。
6. `git log` 中能看到 `v1.1 roadmap` 和后续每个任务一个 commit。
